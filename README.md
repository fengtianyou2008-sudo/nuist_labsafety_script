# nuist_labsafety_script
帮你偷懒
首先这是一个支持zerror题库+言蹊题库+AI复查的帮助你在nuist的实验室安全考试中偷懒的小工具
事实上，这非常的简单，你只需要点击右上角绿色标志，然后选择DOWNLOAD ZIP
接着把它解压缩，然后打开里面那个html文件，这时候你的电脑上就会出现一个网页了
相信你在打开我这个文件之前，肯定用过ocs和report_writer了，没用过也没关系，下面我来手把手教你、
首先如果你的edge浏览器没有装过篡改猴的话，看你浏览器的右上角，没错，那里有个拼图
点开它然后点击获取Microsoft Edge扩展，在新页面的右上角找到搜索框搜索monkey
不出意外的话你已经找到了，那么只需要下载它，然后再次点击右上角小拼图，点管理拓展，然后点篡改猴的详细信息，然后把所有开关都打开
别担心，这不会对你的电脑做什么
接着你就可以开始获取你的脚本了
在之前打开的脚本生成网页里，你需要填写你的zerror题库的配置，言溪题库的配置以及AI的APIkey
空着也没关系，只要有一个填写就能用，只是每空置一个都表示在答题过程中少复查一道
别担心，所有的过程都在你的本地完成，我不会收到这些信息
windows可能会阻止你下载，不过没关系的，所有这个格式的文件都会被警告，保留它
然后拖入浏览器，油猴会帮你装好，就这么简单

那么下面我们来讲讲这个东西能干什么吧
首先，8倍速刷课，并自动完成跳出来的题目
其次，自动完成考试，正确率取决于题库和AI，与我无关

还有一些小bug,但是无关痛痒，我就不修了
1.8倍速播放导致部分内容的完成度不是100%，会挂两遍那个部分，然后就满了，所以懒得修了
2.课程中弹出的题目多选题有时候会只选一个，但是这个的正确率无关痛痒，也没人管，所以懒得修了
3.考试中第100题无法自动作答且不会自动提交，需要你手动选择并提交，但是前面99道都正常，所以懒得修了

最后，作者自己也是喜提96分完成任务，祝你们早日解脱
